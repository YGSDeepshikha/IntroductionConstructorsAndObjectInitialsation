# C++ Library Management System

A C++ application developed to demonstrate fundamental Object-Oriented Programming (OOP) concepts, specifically focusing on class constructors and object initialization.

## Core Features
- **Object Initialization:** Demonstrates default and parameterized constructors to instantiate book and catalog objects.
- **Library Catalog Management:** Provides core functionality to add, search, and manage library items.
- **OOP Principles:** Emphasizes encapsulation, modular design, and clean class structure.

## Tech Stack
- **Language:** C++
- **Compiler:** `g++` / GCC or any standard C++ compiler
